# O Craque — Sistema SSS

MVP do simulador de carreira de futebol baseado em progressão estilo sistema/manhwa.

## Implementado
- Jogador, Sistema, Pontos de Cópia, atributos e talentos roubados.
- Duelos com chance de roubar fragmentos.
- Treino Leve, Pesado e Espartano, com limites de potencial e riscos.
- Progressão de categoria e envelhecimento.
- Dashboard responsivo navy/ciano.
- Aviso de uso de nomes reais para identificação/homenagem.

## Próximas etapas
Contratos e transferências, temporada completa, clubes e competições, recordes, eventos narrativos e persistência em banco de dados.
